# 隐私与公开范围

本仓库从原本机工程按白名单导出并建立全新的 Git 历史，未复用可能含用户数据的旧归档或旧提交。

## 公开内容

- 运行源码、离线测试、构建与校验脚本。
- 使用说明、许可证和 GitHub 工作流。
- 使用模拟账号、模拟接口和临时目录生成的四张界面截图。
- 由清理后的源码重新构建的 Windows 程序与不含运行数据的发行包。

## 不公开内容

- 账号配置、OpenID、Token、服务授权头、DPAPI 密文及备份。
- 历史记录、结构化/文本日志、个人位置与本机模式选择。
- `.env`、证书/私钥、IDE 文件、虚拟环境、缓存和构建日志。
- 旧发行包、迁移材料、开发进度记录及无关项目。

源码中原有的固定服务授权已移除，改为本机环境变量 `PINGAN_API_AUTHORIZATION`。该值不会打包进 EXE，日志脱敏也涵盖当前服务授权值。

`.gitignore` 为后续开发提供防误提交规则，但提交前仍应检查 `git diff --cached`。`data/` 与完整密码备份均属于敏感数据；加密不代表适合公开。

## 本机数据

应用没有新增统计或分析服务。真实运行会为登录、查询任务与提交结果访问学校接口；源码依赖安装与 GitHub 下载分别访问对应服务。离线演示与测试使用模拟接口。

DPAPI 保护依赖当前 Windows 用户，不能阻止已控制该用户会话的软件读取内存或剪贴板。跨设备迁移使用密码加密备份；请自行妥善保存备份密码。
