# 使用说明

首次搭配 OpenID 工具使用，请先阅读 **[从获取 OpenID 到完成第一次签到](OPENID_TO_CHECKIN.md)**，包含两个便携包的下载、微信小程序登录捕获、结果导入、服务授权配置与首次执行核对。

## 第一次运行

解压便携包后可直接启动 EXE。`--demo` 使用临时模拟数据与模拟接口，不读取已有账号，也不执行真实签到。

真实运行需要先设置 `PINGAN_API_AUTHORIZATION` 环境变量，再重新启动程序；完整值通常包括授权方案前缀。程序不会附带、推导或自动获取该授权值。请只使用通过授权渠道取得的凭据。

在账号页添加自己的 OpenID，也可以点击“导入 OpenID 工具结果”，选择 [python-openid-tool](https://github.com/Yzcat766/python-openid-tool) 导出的 `output/openid.json`、TXT 或 env 文件，预览并确认导入。OpenID 工具不会导出服务授权头，仍需单独配置上面的环境变量。

先使用“检查账号（只读）”核对账号与任务。该操作会联网登录和查询，但不提交签到。登录成功与签到成功是不同状态。

## 执行与计划

核对账号、位置与服务端任务时段后，选择账号范围并手动执行。首次安装的自动计划、登录启动、启动隐藏和防睡眠默认关闭。

自动计划支持每日、工作日和指定日期；可配置有限重试。自动执行只匹配服务端日期为当天、当前开放的任务；存在多个候选任务时需要配置精确名称或人工处理。

应用运行或留在托盘中才能执行计划。锁屏不等于睡眠；睡眠和关机期间不会执行。程序没有注册 Windows 唤醒任务。移动程序后如启用了登录启动，请主动检查并修复启动项。

“关闭窗口”可隐藏到托盘。更新、替换 EXE 或切换数据之前，请从托盘真正退出。相同数据目录不能由桌面与命令行同时执行。

## 数据与备份

默认便携模式为 EXE/源码旁的 `data/`，也可切换到 `%LOCALAPPDATA%/CSUFT-Pingan/data`。模式选择保存于程序旁的 `data-mode.json`，`--data-dir` 可以显式指定目录。

OpenID 通过 Windows 当前用户 DPAPI 保护。复制 DPAPI 数据到其他用户或电脑通常无法解密；跨电脑迁移请使用程序内的完整密码备份。完整备份包含账号与位置，密码遗失后无法恢复。

恢复之前会展示预览、保存本机回退副本；恢复后自动计划默认关闭，请重新核对。原始配置、完整备份、历史、日志与精确位置均不应提交到 GitHub。

## 常用命令

```powershell
./CSUFT-Pingan.exe --demo
./CSUFT-Pingan.exe --data-dir 'D:/PinganData'
# 以下命令会使用真实配置并联网：
./CSUFT-Pingan.exe --run-once
./CSUFT-Pingan.exe --run-once --scheduled
```

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 提示未配置服务授权头 | 在启动程序的同一环境设置变量，完全退出后重新启动 |
| OpenID 无效或登录失败 | 核对自己的凭据与账号绑定，必要时使用官方入口 |
| 位置或任务规则不符合 | 核对服务端要求、实际位置及任务时段，程序不会跳过校验 |
| 凭据无法解密 | 回到原 Windows 用户/电脑，使用密码备份恢复或重新输入 OpenID |
| 到时未执行 | 检查程序是否运行、设备是否唤醒、计划是否保存，以及日志中的准备状态 |
| 想向他人反馈问题 | 只提供脱敏错误与复现步骤，先移除身份、凭据、路径和精确位置 |
